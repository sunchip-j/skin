# Docs

Markdown documents for this project are stored here.

## Structure

- `README.md`: docs index and storage guide
- `project-analysis.md`: current architecture, data flow, and maintenance guide
- `products-coverage.md`: product recommendation coverage snapshot
- Add project notes, specs, decisions, and references as `.md` files in this folder.

## Naming

- Use lowercase kebab-case for file names.
- Example: `skin-type-result-copy.md`
