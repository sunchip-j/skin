# ILINA 디자인 기준

기준일: 2026-10-29. 기존 화면을 유지하면서 후속 변경 시 참고할 기준이다.

- 서비스 화면은 연한 녹색 배경(`#f7fbf8`), 흰색 카드, 에메랄드 강조색과 진한 슬레이트 본문을 사용한다. 시작 화면은 최대 28rem의 단일 열이고, 읽기 중심의 브랜드 콘텐츠는 최대 3xl 폭을 사용한다.
- 제목은 굵게, 본문은 충분한 줄 간격으로 구분한다. 작은 보조 정보도 배경과 구분되는 색을 사용하고, 중요한 안내는 장식용 글자처럼 작게 취급하지 않는다.
- 주요 동작은 넓은 에메랄드 버튼으로 표현한다. 작은 아이콘 버튼, 제품 링크, 돌아가기 및 푸터 링크는 44px 이상의 높이를 확보하고 키보드 초점을 표시한다.
- 카드는 둥근 모서리와 옅은 테두리 또는 그림자를 사용한다. 제품 태그는 작은 연녹색 배경으로 제품명보다 낮은 위계를 유지한다.
- `ilina.kr`은 공통 진단 화면에 자료 링크를 더하고, `/company`와 소개·안내 글에는 별도 브랜드 레이아웃을 쓴다. `skin.ilina.kr`은 공통 진단 화면과 서비스 안내를 사용한다. 화면의 목적에 따라 폭과 구성을 달리한다.
- 공통 화면 변경은 두 호스트에 영향을 준다. 문구, 데이터, 라우팅 및 메타데이터 변경은 별도 결정으로 다룬다. 화면별 검증 기록은 `verification/`에 둔다.
