# 애드센스 콘텐츠·추천 링크 개선 검증

기준: 2026-11-12 KST. 기존 사용자 수정(큐레이터 15개, 고지, 브라우저 검증 선택자)을 포함한 소스 복사본에서 검증했다. 원본 반영 시 파일 해시로 동일성을 확인한다.

## 자동 검증

- Next.js 프로덕션 빌드 통과. 타입 검사 및 app/features/관련 브라우저 스크립트 ESLint 통과.
- 기존 `verify-service-hosts.py`: 두 호스트 canonical/OG/noindex/404/리디렉션/robots 통과. 루트 사이트맵 40개, 서브도메인 2개, 루트 42개 공개 탐색 경로와 내부 링크/앵커 확인.
- `verify-content-readiness.py`: 두 호스트의 33문항·실제 점수 범위·가능한 모든 합계의 단일 분류 구간, 16유형별 인접 유형 링크, 16개 제품 페이지의 근거·주의점·수수료 고지와 링크 검증.
- 17개 활성 제품에 근거가 정확히 대응하며 큐레이터 링크는 15개. 구달 선크림·일리윤150ml는 구매 연결 보류. 큐레이터 구매 링크에 sponsored/noopener/noreferrer 적용.
- 접힌 추가 제품도 초기 HTML에 포함되며 브라우저 기본 details/summary로 동작.
- AAD의 7~10일 안내와 원문 링크 반영. 이전 턱선/귀 뒤 며칠 안내 제거.

## 브라우저 확인

- 로컬 프로덕션 서버에서 390×844 뷰포트로 소개와 DSPW 제품 페이지 확인.
- 전체 문항 펼침, 추가 클렌저 펼침, 선정 근거 펼침 동작 확인.
- 임의 테스트 응답으로 33문항 완료 → DRNT 결과 → 새로고침 → 개인 제품 추천 → 결과 복귀 확인. 실제 사용자의 피부 판정이나 임상 정확도 검증은 아님.
- 두 페이지의 문서 가로 폭이 뷰포트를 넘지 않음. 점수표는 좁은 화면에서 자체 가로 스크롤을 허용.
- 상품 카드에서 검토 날짜·직접 사용 후기 아님·현행 정보 변동 가능성·출처·구매 링크 표시 확인.

## 한계

운영 배포 성공은 Git 푸시와 별개다. Search Console/AdSense 계정은 열지 않았다. 제품 17개의 현행 성분·재고·큐레이터 최종 리디렉션을 이번에 전수 재조사한 것이 아니며 10/30 제품 검토 기록을 공개 UI로 옮겼다. 임상 타당성과 전문가 검토, 승인 여부는 검증하지 않았다. 전문 검토와 운영 재신청 조건은 감사 문서에 남겼다.
