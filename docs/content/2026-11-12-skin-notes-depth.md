# 피부 관리 노트 본문 보강

2026-11-12 KST. 사용자가 기존 안내의 깊이가 부족하다고 지적하여 운영 본문을 다시 확인하고, 기존 글 보강과 새 글 작성·운영 반영을 진행했다.

## 확인한 문제와 변경

운영의 기존 네 글에는 본문이 있었지만 설명 문단은 각각 1,288~1,376자에 그쳤다. 목록·레이아웃 외에 독자가 선택 과정을 따라갈 내용이 더 필요했다. 글자 수를 승인 기준으로 사용하지 않고, 각 글이 답하는 실제 질문을 확장했다.

- 기본 루틴: 바르는 순서, 7개 제품을 역할로 옮겨 적는 화장대 사례, 한 가지 변경을 기록하는 방법.
- 번들거림과 당김: 관찰과 추측 구분, 서로 다른 시점의 기록을 비교할 때의 한계, 7일 메모와 다음 행동.
- 새 제품: 이름·용량·판본 대조, 구매 후 확인, 작은 부위 시험과 실제 얼굴 사용 기록 구분, 상담에 가져갈 정보.
- 선크림: 사용량과 노출 부위, 가상 후보 비교, 출근일·야외 활동일의 재도포 준비.
- 신규 `/learn/choosing-a-moisturizer`: 제형·성분 역할·부위별 사용감, 가상 후보 단위 가격 비교와 구매 보류 판단.
- 신규 `/learn/face-washing-without-overdoing`: 세정 대상·방법·세안 후 느낌 구분, 제품별 제거 안내, 운동한 날의 기록과 가상 사례.

각 글의 설명 문단은 약 2,500~2,800자이며 표·FAQ·목차는 별도다. 가상 사례를 실제 후기나 효과 입증으로 표현하지 않았다. 기존 출처·AI 활용·의료 감수의 한계·제휴 안내를 유지했다.

메인과 목록, 피부 관찰 글에는 실제 관찰 방법 설명과 `/skin-observation-note.txt` 다운로드 링크를 추가했다. TXT에는 작성 예시, 7일 빈 기록, 되돌아볼 질문이 있다. 사용자는 기기에서 작성하며 사이트에 제출하는 기능은 없다. 7일은 편의상 분량으로 진단 기간이 아니다.

## 근거 확인

2026-11-12 AAD의 기본 관리·세안·지성 피부·보습제 선택·새 제품 시험·선크림 선택/사용과 NHS 접촉피부염 자료를 다시 열람했다. 신규 보습 성분 설명에는 [DermNet](https://dermnetnz.org/topics/emollients-and-moisturisers)을 추가했다. 글의 문단별 링크에서 일반 안내의 근거를 확인할 수 있다. 자체 예시·표·기록 방법은 이 자료의 장문 번역이 아닌 별도 편집 내용이다.

## 검증

- Next.js 프로덕션 빌드·TypeScript·변경 코드 ESLint 통과.
- 기존 `verify-editorial.py`: 여섯 글의 전체 문단이 양 호스트 초기 HTML에 존재하며 출처 참조·관련 글·표·canonical·Article 구조화 데이터 통과.
- `verify-service-hosts.py`: 루트 47개/서브 2개 사이트맵, 내부 링크·앵커·404·리디렉션·정책 페이지 등 통과. TXT를 포함해 공개 탐색 50개 경로 확인.
- 브라우저: 320/390/1440px × 메인·신규 두 글·관찰 글, 12개 화면에서 가로 넘침 없음, main/h1 각 하나. 모바일 본문과 표를 시각 확인했고 확인 시점의 오류 로그 없음.
- 브라우저 다운로드 이벤트 대기가 종료되지 않아 사용자 중단 후 HTTP 응답과 원본 파일 일치 검사로 다운로드 파일 검증을 전환했다. 브라우저의 파일 저장 완료는 검증했다고 주장하지 않는다.

이번 변경으로 애드센스 승인 여부를 판정하거나 재심사를 신청하지 않았다. 글 수와 분량, 구조화 데이터는 승인 보증이 아니며 운영 반영과 검색·심사 계정 상태는 구분한다.
